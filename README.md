Featured Project

California Earthquake Risk: Story Map Integration of Dashboards and 3D Web Scenes
I developed a public-facing ArcGIS StoryMap that communicates earthquake hazards across California using interactive dashboards, 3D web scenes, and embedded multimedia. The project highlights population exposure near active faults, recent earthquake activity, and preparedness resources, providing a data-driven tool for public awareness and emergency planning.
